## 🗄️ API Endpoints

### All endpoints at: `http://localhost:3002/api/admin`

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/users` | Get all users |
| GET | `/users/:id` | Get user details |
| POST | `/users` | Create user |
| PUT | `/users/:id` | Update user |
| DELETE | `/users/:id` | Delete user |
| POST | `/users/:id/change-password` | Change password |
| GET | `/statistics` | Get statistics |

**Authentication:** JWT token in Authorization header
```
Authorization: Bearer <token>
```

## 🚀 Quick Start (5 Steps)

### Step 1: Run Migration
```bash
psql -U rasa_user -d rasa_db -f admin_migration.sql
```

### Step 2: Start Server
```bash
node backend/admin-server.js
```

### Step 3: Create Admin User
```sql
UPDATE users SET user_type = 'admin' WHERE id = 1;
```

### Step 4: Login
Visit: `http://localhost:3000/login.html`

### Step 5: Access Admin Panel
Visit: `http://localhost:3000/admin_dashboard/admin.html`

## 🔒 Security Implemented

✅ **JWT Token Authentication**
- All API endpoints require valid token
- Tokens expire after 24 hours
- Tokens include user_type information

✅ **Password Security**
- Passwords hashed with bcryptjs
- 10 salt rounds
- No plain text storage

✅ **Role-Based Access**
- Only admin users can access admin API
- Non-admins redirected to login
- Server-side verification

✅ **Data Validation**
- Email uniqueness enforced
- Input validation on all fields
- Parameterized SQL queries (SQL injection prevention)

✅ **Error Handling**
- Proper HTTP status codes
- Error messages without sensitive data
- Logging for troubleshooting
