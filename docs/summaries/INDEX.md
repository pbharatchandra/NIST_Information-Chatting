## 🚀 **Getting Started (TL;DR)**

```bash
# 1. Install dependencies
npm install

# 2. Setup database
psql -U rasa_user -h localhost -d rasa_db -f auth_schema.sql

# 3. Start server
node backend/auth-server.js

# 4. Open browser
http://localhost:3001

# 5. Sign up and chat!
```
