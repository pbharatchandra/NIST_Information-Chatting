SYSTEM ARCHITECTURE:

Signup Form (Frontend):
  ├─ Full Name ← required
  ├─ Email ← required
  ├─ Password ← required
  ├─ Confirm Password ← required
  ├─ Roll Number ← required (NEW)
  └─ Role ← required (student | faculty | alumni)

Backend Endpoints (API):
  POST /api/auth/signup
    Input: email, password, full_name, roll_number, user_type
    Validation: All fields required, roll_number unique, role valid
    Output: token, user{id, email, full_name, user_type, roll_number}
    Routing: Based on user_type
      ├─ student → /student_dashboard/dashboard.html
      ├─ faculty → /faculty_dashboard/dashboard.html
      └─ alumni → /alumni_dashboard/dashboard.html

Database Schema (Required):
  users table:
    ├─ id (PK)
    ├─ email (VARCHAR, indexed, NOT unique)
    ├─ password (VARCHAR)
    ├─ full_name (VARCHAR)
    ├─ user_type (VARCHAR, CHECK IN ('student', 'faculty', 'alumni'))
    ├─ roll_number (VARCHAR, UNIQUE) ← Primary Identifier
    ├─ created_at (TIMESTAMP)
    └─ updated_at (TIMESTAMP)
